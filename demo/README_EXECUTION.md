# Execute the v0.1 Demonstrator

1. Read [JIG_SPECIFICATION.md](JIG_SPECIFICATION.md).
2. Follow [PHYSICAL_CAPTURE_CHECKLIST.md](PHYSICAL_CAPTURE_CHECKLIST.md).
3. Install and test using [QUICKSTART.md](QUICKSTART.md).
4. Record dry runs with [record_multiview.py](record_multiview.py).
5. Validate episodes with [validate_episode.py](validate_episode.py).
6. Apply [ACCEPTANCE_TESTS.md](ACCEPTANCE_TESTS.md).
7. Complete [QUALITY_REPORT_TEMPLATE.md](QUALITY_REPORT_TEMPLATE.md).
8. Obtain review using [EXTERNAL_REVIEW_TEMPLATE.md](EXTERNAL_REVIEW_TEMPLATE.md).

Do not collect real worker data before purpose, rights, privacy and retention are defined and reviewed.
