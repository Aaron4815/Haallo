# Project Control Rule

Documentation for demonstrator v0.1 is now frozen except for corrections and evidence produced by actual execution.

No further planning document should be added before one of these occurs:

1. the physical jig is built,
2. calibration is measured,
3. a dry-run episode is captured,
4. a validator or CI defect is found,
5. external technical feedback requires a change.

Priority order:

1. physical build,
2. equipment test,
3. calibration,
4. five dry runs,
5. ten internal episodes,
6. measured quality report,
7. external review.

The repository must not create the appearance of progress through documents alone.
